How it works
  • Follows native links from this tab, open client first, for up to 300 pages. Individual employee and facility records are skipped.
  • Never submits a dialog or accepts terms, and returns the tab to where it started.
  • Stops after three empty pages, an open notice or a failed screenshot. Resume continues and retries failures.
  • Screenshots only work on the tab AC Tools was opened from. Screenshots and test data include any record text on screen.
  • Progress is saved in the browser as it goes, but the export is the real copy.
  • Use the same window size and zoom for runs you want to compare.
