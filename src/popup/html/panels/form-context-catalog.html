Forms for Webforms

Exports form definitions and linked subforms from Northern Health UAT. Open the capture in Webforms or Form Config → Form library. Captures exclude patient answers, templates and attachments. Include archived forms or older versions when needed.

Downloads a versioned capture for Webforms. No definitions are changed in AlayaCare.

Push edited forms from Webforms

In Webforms Form Config → Form library, export the edited form for draft push. Open Northern Health UAT Form Settings, choose the package here, then review and create new draft copies. Linked child forms are created first.

Draft creation requires your signed-in Chrome session. Source changes and unsupported references stop the push. Publication remains in AlayaCare.

Word templates and child PDFs

Upload a Word template to an existing form in NH UAT Form Settings. Preserve its field tags. For child printing, enter the parent submission ID and review its direct child entries. Each entry gets a separate native PDF; the standard parent PDF includes all entries.

Uses the signed-in UAT session. No approval, signing or publication changes are made.

Manual tenant snapshot

Reads form-context fields, profile attributes, and supported option lists from the active signed-in AlayaCare tenant. Nothing is sent to Webforms automatically.

  • Exports binding tags and native field types
  • Includes resolved dropdown options where available
  • CSV or styled Excel merges live Patient fields with the reviewed documentation table
  • Contains configuration metadata only—no client records
